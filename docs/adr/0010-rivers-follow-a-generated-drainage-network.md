# Rivers follow a generated drainage network

Rivers run along a drainage network that world generation lays out from the seed: courses, confluences, catchments, lake basins, and underground channels through karst. A river's discharge follows from that network, summing its tributaries, baseflow from the water table, runoff and melt from its catchment, and the outflow of lakes upstream, so it swells in a wet season and runs dry in a drought. Vanilla rivers are still water at sea level, and letting volumetric water find its own way downhill would need the whole map loaded to know where any river runs. Generating the network keeps a river's course and discharge computable for any place and moment, as [ADR 0004](0004-feudum-owns-the-weather.md) does for the weather, so an unloaded catchment still feeds the river a player stands in. The cost is that world generation must offer the network and a groundwater baseline from the seed alone, under the same rule [ADR 0006](0006-weather-reads-the-generated-terrain.md) sets for base height.
