# Health lives in a pool for each body part

A body's health is split into pools, one for each part of the body. A human has seven: the head, the chest, and a left and right arm and leg. A body goes down when a vital pool, the head or the chest, reaches 0, and a limb at 0 is disabled. One pool per body, as in vanilla, with injuries attached to the struck region, would have been simpler, and would have left players one value to read. But a medieval fight turned on where a blow landed: a cut to the sword arm ended a duel, and a smashed leg ended a march. Pools make that true without a separate rule for each limb, and sides make a shield arm and a sword arm differ. The cost is seven values to save, heal, and cue on every human, and a body panel to show them without a meter. Armor's coverage stays per region, so its five struck regions also need a mapping to the pools. Weapons must set damage against pools of this size, and every body profile must declare its own pools.
