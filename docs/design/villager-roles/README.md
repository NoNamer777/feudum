# Villager roles

The roles a villager can hold, such as an office or a title. A role gets its own page in this folder once its design is settled. The planned [Villagers](https://github.com/NoNamer777/feudum/issues/46) mechanic owns the villager model that roles run on, and the [design index](../README.md) lists the other areas.

## Designed

None yet.

## Planned

Roles that came up while designing other topics and wait for a design of their own are [open issues](https://github.com/NoNamer777/feudum/issues?q=is%3Aissue%20is%3Aopen%20label%3Adesign%20label%3Avillager-roles) labeled `design` and `villager-roles`.
