# Design

The design of Feudum, split into areas. Each area's index lists its designed topics, each with its own page, in alphabetical order. The planned topics still waiting for a page are [issues labeled `design`](https://github.com/NoNamer777/feudum/issues?q=is%3Aissue%20is%3Aopen%20label%3Adesign), with a label for their area. [GLOSSARY.md](../../GLOSSARY.md) defines the terms these pages use, and the [decisions](../adr/) record the choices that cut across areas.

- **[Mechanics](mechanics/README.md)**: the game's systems, such as time and villages.
- **[World generation](world-generation/README.md)**: the biomes, structures, and villages of the generated world.
- **[Content](content/README.md)**: the blocks, items, and entities that replace vanilla's.
- **[Villager roles](villager-roles/README.md)**: the offices and titles a villager can hold.
