# Roles

Each document describes one villager role: the work it does for the village, and the items, blocks, and behaviors it depends on.

## Planned

These roles have no document yet:

- **Farmer**: plows and sows in spring and harvests in autumn, so the village has food to store for winter.
- **Woodcutter**: fells trees, mostly in winter, and supplies the firewood that heats the village's homes.
- **Builder**: raises and repairs the village's buildings, mostly in summer.
