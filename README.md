# Feudum

A Minecraft mod in which players manage medieval fantasy villages.

The name comes from *feudum*, the medieval Latin word for a fief and the root of "feudal".

## Status

Early development: the repository holds no mod code yet.

## Design

The [docs](docs/README.md) hold the design of Feudum: its mechanics, world generation, content, and villager roles, and the decisions behind them. [GLOSSARY.md](GLOSSARY.md) defines the terms they use.
